# My Toolbox

个人软件收藏仓库，收录平时收集的实用小工具，方便随时随地下载，同时作为博客中软件推荐文章的下载源。

> 大部分工具来自网络收集，版权归原作者所有，仅供个人学习交流使用，请勿用于商业用途。

## 目录结构

```
my-toolbox
├── system         # 系统工具：清理优化、硬件驱动、安全防护、备份还原
├── network        # 网络工具：浏览器、插件、下载器、软件
├── productivity   # 效率办公：截图OCR、剪贴板、文档PDF、笔记
├── media          # 影音图像：播放器、转码、修图、录屏
├── dev            # 开发工具：编辑器、终端、抓包、API 调试
├── game-tools     # 游戏工具：存档备份、修改器、模拟器
└── others         # 不好归类的
```

## 命名规范

`工具名_版本.exe`，例如：`Everything_1.4.1.exe`

文件名统一使用英文或拼音，避免中文文件名在直链中产生编码问题。

## 直链下载

GitHub 直链（国内访问可能较慢）：

```
https://github.com/<你的用户名>/my-toolbox/raw/main/<路径>/<文件名>
```

jsDelivr 加速直链（国内访问快，单文件 20MB 以内）：

```
https://cdn.jsdelivr.net/gh/<你的用户名>/my-toolbox@main/<路径>/<文件名>
```
